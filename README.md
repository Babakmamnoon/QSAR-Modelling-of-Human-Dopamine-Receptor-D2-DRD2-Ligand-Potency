## The short version

This project predicts DRD2 binding potency (pIC50) from structure. Fitting a model to
fingerprints is the easy part and it is four lines of code. The work here is in the
parts that decide whether the resulting number means anything:

- the data is **derived from a live ChEMBL query**, not read from a CSV of unknown origin;
- curation is **audited row by row**, and it removes five compounds whose recorded
  potencies were physically impossible;
- evaluation uses a **scaffold split**, with the random-split result published beside it
  so the optimism a random split introduces is visible rather than hidden;
- every metric carries a **95% bootstrap confidence interval**;
- the model is benchmarked against a **1-NN similarity lookup** and a **mean predictor**,
  because a model that cannot beat those has learned nothing;
- predictions ship with an **applicability-domain flag** and a **conformal interval**.

The headline result is modest, and the most useful thing in this repository is the
machinery that shows *why* it is modest rather than dressing it up.

```bash
pip install -e .
python -m drd2_qsar.run --config configs/drd2.yaml   # the whole pipeline, one command
```

## 1. Results

> **Provenance note.** The numbers below were produced in a build environment with no
> route to `ebi.ac.uk`, so the pipeline fell back to the cached legacy snapshot
> (605 curated compounds, already truncated to IC50 < 1000 nM upstream). They are
> **real numbers from a real run** and every figure in this README was generated by
> the code in this repository — but they are not the numbers a full-dynamic-range
> ChEMBL pull will produce. Regenerate them on a machine with ChEMBL access:
> `python -m drd2_qsar.run --config configs/drd2.yaml --force-refresh`.
> Every run stamps its provenance into `reports/metrics.json` under `data_provenance`,
> so a reader can always tell which kind of run they are looking at.

### Primary model — Random Forest on ECFP4, scaffold-split test set (n = 121)

The primary model is selected by **5-fold scaffold-grouped cross-validation over the
train+validation pool**. The test set is used exactly once.

| Metric | Value (95% bootstrap CI) |
|---|---|
| RMSE | **0.722 [0.641, 0.810]** |
| R² | 0.150 [−0.009, 0.285] |
| MAE | 0.570 [0.500, 0.658] |
| Median AE | 0.489 [0.334, 0.583] |
| Spearman ρ | 0.398 [0.225, 0.543] |
| Pearson r | 0.424 [0.265, 0.566] |
| Kendall τ | 0.279 [0.155, 0.391] |
| Within ±0.5 log | 52.9% [43.0, 61.2] |
| Within ±1.0 log | 82.6% [75.2, 89.3] |

Across **10 repeated scaffold splits**: RMSE 0.697 ± 0.037, R² 0.199 ± 0.075,
Spearman ρ 0.462 ± 0.073.

### How to read these numbers

Three comparisons make the result interpretable. None of them is optional.

**Against the assay-noise ceiling.** Pooled multi-laboratory ChEMBL IC50 data has a
reproducibility limit of roughly **0.68 log units RMSE** (Kalliokoski et al. 2013). The
model sits at 0.722 — within about 0.04 log units of the floor. There is very little
headroom left for *any* model on this data.

**Against the mean predictor.** Predicting the training mean gives RMSE 0.788
[0.716, 0.862]. The Random Forest's interval **overlaps** it. On a single scaffold
split, this model does not convincingly beat a constant. That sounds damning until you
notice the reason: this dataset is potency-truncated, so the pIC50 standard deviation
is only 0.77. When the target barely varies, R² is structurally near zero and RMSE
near the mean-predictor's value regardless of model quality. The separation is real but
small, and it only becomes visible across repeated splits (R² 0.199 ± 0.075, positive
in every repeat) and in the y-scrambling test below.

**Against a similarity lookup.** 1-NN Tanimoto gives RMSE 0.888 [0.780, 0.999] — the
*worst* rung on the ladder. This is worth dwelling on: under a scaffold split, the
nearest training neighbour is by construction in a different chemical series, so
copying its potency is actively misleading. The same baseline under a random split
scores 0.807, and the gap is a clean measure of how much a random split rewards
memorisation.

**The signal is real, though small.** Y-scrambling over 100 label permutations gives a
null R² of −0.151 ± 0.086 against the real model's 0.150, for an empirical
**p = 0.0099**. The model is learning structure–activity information, not fitting the
split.

### The baseline ladder

| Model | Scaffold split RMSE | Random split RMSE | Optimism (Δ) |
|---|---|---|---|
| **Random Forest** | **0.722 [0.641, 0.810]** | 0.619 [0.527, 0.701] | 0.103 |
| SVR (RBF) | 0.735 [0.655, 0.812] | 0.584 [0.507, 0.652] | 0.151 |
| Mean predictor | 0.788 [0.716, 0.862] | 0.799 [0.729, 0.868] | −0.011 |
| XGBoost | 0.818 [0.731, 0.911] | 0.637 [0.539, 0.741] | 0.181 |
| Ridge | 0.879 [0.781, 0.983] | 0.699 [0.595, 0.801] | 0.180 |
| 1-NN Tanimoto | 0.888 [0.780, 0.999] | 0.807 [0.688, 0.922] | 0.081 |

A random split makes every learned model look 0.08–0.18 log units better than it is,
and leaves the mean predictor unchanged — exactly the signature of memorised
congeneric series. **This table is the single most important result in the
repository.**

### Applicability domain

Test error is a clean monotone function of distance from the training set:

| Mean Tanimoto to 5 nearest training compounds | n | Test RMSE (95% CI) |
|---|---|---|
| 0.216 – 0.409 | 24 | 0.930 [0.734, 1.109] |
| 0.409 – 0.522 | 24 | 0.797 [0.579, 1.015] |
| 0.522 – 0.606 | 25 | 0.645 [0.468, 0.811] |
| 0.606 – 0.663 | 23 | 0.662 [0.485, 0.803] |
| 0.663 – 0.766 | 25 | **0.512 [0.308, 0.699]** |

Inside the model's neighbourhood it predicts to ~0.5 log units; outside it, ~0.93. That
factor of nearly two is the practical content of the model — it tells a project team
which predictions to act on. 8.3% of the test set falls outside the domain boundary
(5th percentile of training leave-one-out neighbour similarity, 0.328).

### Uncertainty calibration

Split-conformal prediction at a nominal 80% level gives an interval of **±0.892 log
units** with **74.4% empirical coverage**. The shortfall is expected and is reported
rather than hidden: the conformal guarantee assumes exchangeability between
calibration and test data, and a scaffold split violates that assumption *by design*.
An honest 74% is more useful than an asserted 80% that does not hold.

### Representation ablation

| Featurizer | Features | Test RMSE (95% CI) |
|---|---|---|
| ECFP4 + RDKit descriptors | 2265 | **0.731 [0.641, 0.826]** |
| RDKit descriptors | 217 | 0.732 [0.648, 0.822] |
| FCFP4 | 2048 | 0.748 [0.661, 0.841] |
| ECFP6 | 2048 | 0.750 [0.668, 0.836] |
| MACCS keys | 167 | 0.816 [0.723, 0.925] |
| ECFP4 | 2048 | 0.818 [0.731, 0.911] |

Every interval overlaps every other. **The representation is not the bottleneck here** —
the data is. Note also that 217 physicochemical descriptors match 2048 circular
fingerprint bits, which on a scaffold split is what you would expect when the model is
leaning on bulk properties that transfer across series rather than on series-specific
substructure.

## 2. What changed from v0, and why

The first version of this project was a clean, short notebook that fit a
`HistGradientBoostingRegressor` to ECFP fingerprints and plotted the result with
Yellowbrick. It reported train R² = 0.741 and test R² = 0.374. Here is what was wrong
with it, in order of severity.

| # | Defect in v0 | Consequence | Fix |
|---|---|---|---|
| 1 | Five compounds with pIC50 up to **16.4** (sub-femtomolar) | Squared-error loss is dominated by its largest residuals; five points out of 631 were bending the whole fit. Visible as residuals of −4.8 and −6.7 in the v0 residual plot, and as a regression line pulled to a single far outlier in the v0 prediction-error plot. | Plausibility window on pIC50 of [3, 11], with rejected rows printed |
| 2 | Those five are **dopamine, norepinephrine, serotonin** and two catechol aminotetralins — all **agonists** | Modelling agonist potency inside an "inhibitor" model is a category error, not a modelling choice | `action_type` lookup + documented reference list + `action_type_policy` |
| 3 | `train_test_split(df)` with no arguments | No `random_state` (irreproducible); silently 25% not the 80/20 the README claimed; and **random**, so congeneric analogues straddled the split | Seeded three-way Bemis–Murcko scaffold split, with the random split published alongside |
| 4 | 50/631 SMILES carried `Br.`/`Cl.` salt components | The hydrobromide and the free base become different feature vectors with the same label — pure injected noise | RDKit largest-fragment + uncharge + canonical tautomer standardization |
| 5 | Deduplication by ChEMBL ID | Salt forms and stereo-unspecified entries of one parent survive as independent rows | Deduplication on the InChIKey connectivity layer |
| 6 | One number from one split, no intervals | A ±0.15-wide R² interval was reported as a point estimate | 1000-resample bootstrap CIs on every metric; 10 repeated splits |
| 7 | No baseline | Nothing to compare against, so "R² = 0.374" was uninterpretable | Six-rung ladder from mean predictor to XGBoost |
| 8 | No null model | No evidence the model was fitting signal rather than the split | Y-scrambling with an empirical p-value |
| 9 | No applicability domain | No way to know when a prediction is trustworthy | Tanimoto AD with the error-vs-distance curve |
| 10 | README described a pipeline the notebook did not contain | Claimed ChEMBL mining, unit validation, duplicate consensus averaging, stratified partitioning and MSE/RMSE reporting — none of which were in the code | This README describes only what runs |

The last one matters most for a reader's trust, and it is why this document is
deliberately explicit about what the current numbers are and are not.

## 3. Data provenance

The v0 pipeline began by `wget`-ing a pre-made `DRD2.csv` from GitHub. That is the
single biggest reproducibility hole a cheminformatics repository can have: nobody —
including the author six months later — can say what query produced those rows, which
ChEMBL release they came from, or what was filtered out before they were written.

Here the dataset is **derived**, and the derivation is code (`src/drd2_qsar/chembl.py`).
The query is explicit about four things that silently corrupt public-data QSAR models
when left implicit:

```yaml
chembl:
  target_chembl_id: CHEMBL217        # human Dopamine Receptor D2
  standard_types: [IC50]
  assay_type: B                      # binding assays only
  standard_relation: "="             # drop censored (>, <) measurements
  standard_units: nM                 # checked, not assumed
  target_organism: Homo sapiens
```

- **`standard_relation == '='`.** A censored result (`IC50 > 10000`) is real information
  but it is not a regression target. Treating `>` as `=` teaches the model that a
  compound which failed to show activity has exactly the potency of the detection limit.
- **`assay_type == 'B'`.** Binding assays only, so functional and ADMET readouts are not
  pooled into one "potency" column.
- **`standard_units == 'nM'`**, checked rather than assumed.
- **ChEMBL's own `data_validity_comment` flags** are honoured. These are the curator
  warnings that catch transcription and unit errors, and they cost nothing to use.

Every pull writes `data/raw/CHEMBL217_pull_manifest.json` recording the ChEMBL release,
the pull timestamp, the full query and the row count. The raw pull is cached, so
re-running does not silently pick up a different dataset after ChEMBL ships a new
release — and does not hammer the EBI's servers.

If ChEMBL is unreachable, the pipeline falls back to a cached snapshot, marks
`source: legacy_snapshot` in the manifest, and logs a loud warning. It never pretends
a fallback was a live query.

## 4. Curation

Curation is where the answer actually changes, and it is the stage most QSAR notebooks
skip. Every stage logs its row counts to `reports/curation_audit.csv`, and every removed
record is written to `reports/rejected_records.csv` **with its reason** — nothing
disappears unexplained.

![Curation audit](reports/figures/fig00_curation_waterfall.png)

| Stage | Rows before → after | Removed | Reason |
|---|---|---|---|
| Raw pull | 631 → 631 | 0 | rows returned by ChEMBL |
| Missing fields | 631 → 631 | 0 | null SMILES or activity value |
| Censored measurements | 631 → 631 | 0 | kept only exact `=` |
| Units | 631 → 631 | 0 | kept only nM |
| ChEMBL validity flags | 631 → 631 | 0 | curator-flagged suspect records |
| Numeric activity | 631 → 631 | 0 | value must be positive and numeric |
| **Plausibility window** | **631 → 626** | **5** | **pIC50 outside [3, 11]** |
| Standardization | 626 → 626 | 0 | 50 multi-component inputs desalted |
| Element/size sanity | 626 → 624 | 2 | heavy-atom count outside [8, 70] |
| Mechanism policy | 624 → 624 | 0 | `keep_all` |
| Activity cutoff | 624 → 624 | 0 | **not applied** — full dynamic range retained |
| InChIKey generation | 624 → 624 | 0 | connectivity-layer key |
| **Replicate aggregation** | **624 → 605** | **19** | median over 15 multi-measurement parents; 2 dropped for spread > 1 log |
| **Final** | **605** | | modelling-ready unique parent structures |

### The five impossible compounds

| ChEMBL ID | Recorded pIC50 | Implied IC50 | What it actually is |
|---|---|---|---|
| CHEMBL26736 | 16.40 | 40 aM | 2-aminotetralin catechol — **agonist** |
| CHEMBL225230 | 15.30 | 0.5 fM | aporphine — **agonist** |
| CHEMBL59 | 14.10 | 8 fM | **dopamine** — the endogenous agonist |
| CHEMBL1437 | 13.10 | 80 fM | **norepinephrine** |
| CHEMBL39 | 12.52 | 0.3 pM | **serotonin** |

No small molecule binds a GPCR at attomolar affinity. These are unit-handling errors —
µM or mM values recorded as nM — and they are also all agonists, so they violated the
project's own stated scope twice over.

Other curation decisions worth stating:

- **Deduplication on the InChIKey connectivity layer**, not on the ChEMBL accession, so
  salt forms and stereo-unspecified entries of one parent collapse together.
- **Replicates aggregated by median**, and compounds whose replicate measurements span
  more than **1 log unit** are *dropped*, not averaged. When two papers disagree by two
  orders of magnitude the truth is not knowable from this data, and averaging produces a
  confident-looking wrong number.
- **The `IC50 < 1000 nM` activity cutoff is disabled by default.** See
  [Limitations](#13-limitations--stated-not-buried) for why this matters more than
  anything else in the config.

## 5. Splitting: scaffold, not random

ChEMBL target sets are dominated by congeneric series — dozens of close analogues
published together in one paper. A random split scatters those analogues across the
train/test boundary, so the test set mostly measures how well the model interpolates
within series it has already memorised.

A **Bemis–Murcko scaffold split** forces whole chemical series into one partition. The
score it produces is lower, and it is the one that predicts what happens when the model
meets next quarter's chemistry.

| Partition | n | Fraction | pIC50 mean ± SD | Scaffolds |
|---|---|---|---|---|
| train | 424 | 70.1% | 7.39 ± 0.82 | 151 |
| validation | 60 | 9.9% | 7.16 ± 0.79 | 60 |
| test | 121 | 20.0% | 7.25 ± 0.77 | 98 |

Two guarantees are **asserted in code** (they raise, they do not warn) and covered by
tests that plant a deliberate leak to prove the detector fires:

- no Bemis–Murcko framework appears in two partitions;
- no identical structure (by InChIKey connectivity) appears in two partitions.

The split is seeded and reproducible. It is also genuinely *seed-dependent* — an earlier
version ordered scaffold groups deterministically by size, which meant the seed did
nothing and the multi-seed stability analysis reported a variance of exactly zero. A
split that cannot vary cannot measure split variance; the seeded tie-break fixes it.

Random, Butina-cluster and temporal splits are also implemented
(`src/drd2_qsar/splits.py`). The random split is computed on every run for the
side-by-side comparison in §1.

## 6. Modelling and benchmarking

**The ladder.** A QSAR result is only interpretable relative to what a trivial method
achieves on the same split:

1. `dummy_mean` — predicts the training mean. Anything below this is broken.
2. `knn_tanimoto` — 1-NN by Tanimoto similarity. "Copy the most similar molecule you
   have already measured." On congeneric sets this is genuinely hard to beat, and a
   model that fails to beat it has learned nothing a lookup table lacks. It is also the
   baseline almost always omitted, which is why so many published QSAR models are
   functionally slow lookup tables.
3. `ridge` — tests whether the SAR is essentially additive.
4. `random_forest`, `svr` (RBF), `xgboost` — the non-linear workhorses.

**Model selection uses scaffold-grouped 5-fold CV over the train+validation pool.**
Selecting by test score is a subtler form of leakage — the test set stops being held out
the moment it decides anything. Selecting on a single 60-compound validation slice turns
out to be too noisy to be safe: in development it picked XGBoost, which then scored
*worse than the mean predictor* on test. Grouped CV picks Random Forest, consistent with
the full ladder.

| Model | Grouped-CV RMSE (mean ± SD across folds) |
|---|---|
| **Random Forest** | **0.740 ± 0.201** |
| SVR | 0.761 ± 0.176 |
| XGBoost | 0.772 ± 0.189 |
| Ridge | 0.851 ± 0.194 |
| 1-NN Tanimoto | 0.948 ± 0.344 |

Those fold standard deviations (~0.2 log units) are larger than the gaps between the top
three models. That is the honest reading: **on this dataset the top three are not
distinguishable**, and any claim that one "wins" is reading noise.

## 7. Validation

Four checks, each closing a different way of fooling yourself.

**Nested cross-validation** (scaffold-grouped outer folds, randomized search inner).
Tuning inside the folds you score on leaks the answer into the tuning. Result:
RMSE 0.755 ± 0.201, R² 0.051 ± 0.495, Spearman ρ 0.396 ± 0.330. The enormous R²
spread across outer folds is itself the finding — some scaffold groups are simply not
predictable from the others.

**Y-scrambling** (OECD QSAR validation principle 4), 100 permutations. Shuffle the
training labels and refit; a model learning real SAR collapses to R² ≈ 0.

| | R² |
|---|---|
| Real model | 0.150 |
| Permuted labels | −0.151 ± 0.086 |
| **Empirical p-value** | **0.0099** |

**Repeated splits**, 10 seeds: RMSE 0.697 ± 0.037, R² 0.199 ± 0.075. A single split's
score is a random variable, and its spread is frequently larger than the gap between two
models being compared.

**Learning curve** with ±1 SD bands across repeats — does more data help, or has this
endpoint saturated? See `reports/figures/fig08_learning_curve.png`.

## 8. Uncertainty

Two questions a project team will actually ask, neither of which an R² answers.

**"Can I use this model on my compound?"** The applicability domain is the mean Tanimoto
similarity to the *k* = 5 nearest training compounds, with the boundary at the 5th
percentile of the training set's own leave-one-out neighbour similarity. The useful
output is not the in/out flag — it is the **error-versus-distance curve** in §1, which
quantifies how fast predictions degrade outside the training neighbourhood.

**"How wrong is this specific prediction likely to be?"** Split-conformal prediction
converts held-out calibration residuals into an interval with a distribution-free
coverage guarantee, using the finite-sample-corrected quantile
`ceil((n+1)(1−α))/n`. The caveat is stated up front rather than buried: that guarantee
assumes exchangeability, a scaffold split deliberately breaks it, and the observed
74.4% against a nominal 80% is the size of that violation.

## 9. Interpretation

**SHAP mapped back to chemistry.** TreeSHAP runs exactly on the Random Forest. A bit
index is meaningless on its own, so `interpret.top_bit_substructures` traces each
influential bit to a molecule that sets it and the atom environment responsible —
"bit 1174" becomes a highlighted substructure drawn on a real compound.

When the selected model is *not* tree-based (an SVR, say), the pipeline does not fall
back to KernelSHAP — on 2048 features that is hours of compute for an approximation.
It instead fits a gradient-boosted **surrogate** on the primary model's own predictions,
explains that exactly, and **reports the surrogate's fidelity R²** so the reader knows
how much to trust the attribution. Labelling the approximation is the point.

**Activity cliffs.** 25 pairs exceed Tanimoto ≥ 0.70 with |ΔpIC50| ≥ 2.0. They are where
every similarity-based model fails, and the test-set errors confirm it:

| | n | Mean abs. residual |
|---|---|---|
| Not on a cliff | 120 | 0.561 |
| On an activity cliff | 1 | 1.634 |

One test compound is a small sample, but the direction is unambiguous and the full pair
list is in `reports/activity_cliffs.csv`. The SALI landscape
(`fig18_cliff_landscape.png`) shows the whole structure–activity surface with the cliff
region marked.

## 12. Reproducing this work

```bash
git clone https://github.com/Babakmamnoon/QSAR_Modeling_for_Dopamine_Receptor_D2_Inhibitors
cd QSAR_Modeling_for_Dopamine_Receptor_D2_Inhibitors

conda env create -f environment.yml && conda activate drd2-qsar
# or: pip install -e ".[dev,conformal]"

python -m drd2_qsar.run --config configs/drd2.yaml      # full pipeline (~14 min)
python -m drd2_qsar.run --config configs/drd2.yaml --quick   # smoke run (~3 min)
pytest tests -q                                          # 65 tests
```

Useful flags: `--force-refresh` (re-query ChEMBL), `--no-figures`, `-v`.

**Predicting on new compounds:**

```bash
python -m drd2_qsar.predict \
    --model models/drd2_qsar_model.joblib \
    --input my_compounds.smi \
    --output predictions.csv
```

Every prediction returns the predicted pIC50 **plus** an applicability-domain flag, a
conformal interval, and the nearest training neighbour with its measured potency — so a
chemist can see immediately what the prediction is based on. Input structures are passed
through the same standardization used in training, so a salt form in the query file does
not silently become a different molecule from the one the model saw.

**Reproducibility.** One global seed, set once and logged. Every run writes
`reports/metrics.json` containing the config hash, the full environment manifest
(package versions, git revision), the data provenance manifest and every metric with its
interval. Two runs of the same config against the same cached pull produce identical
numbers.

## 13. Limitations — stated, not buried

1. **Potency truncation is the dominant limitation.** The current dataset is truncated to
   IC50 < 1000 nM, so the model has **never seen an inactive compound**. Its pIC50 SD is
   only 0.77, which means R² is structurally low no matter how good the model is, and
   RMSE cannot fall far below the mean predictor's. More importantly, **this model
   cannot be used for virtual screening**: presented with a random library it has no
   basis on which to call anything inactive. It can only rank within an already-potent
   series. The default config disables the cutoff; the fix is a full-dynamic-range
   ChEMBL pull.
2. **Mechanistic heterogeneity.** ChEMBL annotates mechanism only for well-studied
   compounds, so agonists and antagonists may still be pooled in the unlabelled
   majority. The `action_type_policy` mitigates this; it does not solve it.
3. **Congeneric coverage.** A large fraction of compounds sit on a handful of scaffolds.
   The scaffold split makes the *evaluation* honest; it does not make the *coverage*
   better. Whole regions of DRD2-relevant chemistry are simply absent.
4. **Assay heterogeneity.** Pooled multi-laboratory IC50 data carries a reproducibility
   floor of ~0.68 log units RMSE. No model can beat it, and one that appears to has
   almost certainly leaked.
5. **Exchangeability.** The conformal coverage guarantee is marginal and assumes
   exchangeability, which the scaffold split violates by design (74.4% vs 80% nominal).
6. **2D only.** No conformational, protein-structural or free-energy information, despite
   DRD2 having good experimental structures (e.g. PDB 6CM4).
7. **Activity cliffs** are enumerated but not solved. No fingerprint-similarity model
   resolves them.
8. **Statistical power.** A 121-compound test set gives R² intervals ~0.29 wide. Most
   model-to-model differences reported here are not statistically distinguishable, and
   the README says so rather than ranking them anyway.

**Safety note.** DRD2 is the principal target of antipsychotic drugs; DRD2 antagonism
carries real clinical liabilities (extrapyramidal symptoms, tardive dyskinesia,
hyperprolactinaemia) and DRD2 agonism carries its own. This model predicts one *in
vitro* binding number and is a research tool only. See [`MODEL_CARD.md`](MODEL_CARD.md).

## 14. Roadmap

1. **Full-dynamic-range rebuild.** Re-pull from ChEMBL without the potency cutoff. This
   is the highest-value change by a wide margin — it is the difference between a
   series-ranking tool and a screening model.
2. **Temporal split** on `document_year`: train pre-2015, test post-2015. The closest
   available approximation to a prospective test. Implemented; awaiting the metadata a
   live pull provides.
3. **Multi-task learning across DRD1–DRD5**, with DRD2/DRD3 selectivity as a second
   endpoint. Selectivity is the real medicinal-chemistry problem here.
4. **Graph neural network (Chemprop D-MPNN)** as a learned-representation arm of the
   ablation, on the same split with the same intervals.
5. **Docking cross-check against DRD2 (6CM4)** for the highest-error compounds, tying the
   ligand-based model to structure.
6. **Uncertainty-guided active learning** — use the conformal intervals to choose which
   compounds to measure next. This is where the model earns its keep in a real project.
